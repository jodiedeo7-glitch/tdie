# Remaining workflow audit and allocation

These are source-backed workstreams, not verified live tasks. `audit/workflow-inventory.csv` in the package enumerates the repository's job headings; `LEGACY_QUEUE_CROSSWALK.csv` preserves every queue section and step.

| Workstream | Create | Execute / verify | Migration boundary |
|---|---|---|---|
| General Skool weekly load and Facebook mirror | ChatGPT, Jodie's voice, current posting SOP | One approved account operator with separate platform read-back | Missing live posting SOP/task list; do not add bulk engagement or DMs |
| Lapsed-member check-in / member list | Read-only segmentation packet | Authorized operator; messages require explicit authorization | Never infer quiet-member outreach approval from a general audit |
| Friday business numbers | Observed source data, ChatGPT analysis | Read-only metrics capture with evidence | Do not infer revenue, customer delivery or causal attribution |
| Friday canon watchdog | Scoped deterministic repository/live scan | Existing GitHub Actions, reports | UTC clock corrected to target 8 AM Eastern; manual runs remain available |
| Website/CRO and article repurposing | ChatGPT specifications, Codex code | Repo review, build as needed, deployed page checks | Preserve current host and canonical routes; no deployment from package |
| Email / Beacons / launches | Approved copy, offer and access mapping | Read-only inventory first; authorized exact changes | Preserve buyer delivery; no Find Your Door restoration |
| Bots and DFY proof samples | ChatGPT instructions and acceptance examples | Codex packaging, image provider, authorized platform loading | Pending prices and missing canon registration hold listing |
| Amazon themed looks | Approved packet from existing factory | One internal Amazon writer | Independent from OOTD and buyer product |
| Brand Closet OOTD | Own licensed/allowed interpretation | One OOTD operator, immediate source-lesson dedupe | Only own links and imagery; separate queue |
| Amazon onsite videos / seasonal Pink Finds | Source-backed scripts and campaign packet | Image/video tools under canon, authorized account operations | No invented eligibility, income or publication results |

| TikTok and LIVE support | Research and scripts when separately requested | Jodie or explicitly authorized account operation | No audio-rights, Seller eligibility or LIVE-policy conclusions in this migration |
| MANIACALLY THOROUGH / STV demo | Separate channel/brand packet | Applicable channel skill, source QA | Preserve explicit no-publish/no-TDIE-commit STV restriction |
| Images / verification | Separate finished production brief | Canon tool/model and artifact QA; verify per originating workflow | An image queue never authorizes publication or changes voice |

Missing sources stay explicit in SOURCE_REGISTER.json. Do not manufacture unavailable SOPs or treat a historical job heading as an active automation. No new recurring schedules are activated by this package.
