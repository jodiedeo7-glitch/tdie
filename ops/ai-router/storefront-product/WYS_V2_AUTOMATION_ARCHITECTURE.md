## Buyer experience

One guided setup produces:
- MY_RECIPE
- MY_SCHEDULED_TASKS
- browser-lock
- storefront-log
- pin-drafts
- Runs table
- buyer-specific destinations
- buyer-specific disclosure

### Stage 2 — Creative preparation
AI or buyer prepares:
- theme
- products
- affiliate links
- destination
- image
- pin copy

### Stage 3 — Live execution
Browser/computer-use agent or buyer:
- creates/verifies list or site page
- uploads pin
- schedules
- verifies scheduled result

### Stage 4 — Recovery
Missed-run sweep:
- reads Runs
- detects actually missed tasks
- respects lock
- runs once
- records catch-up

---

# Automation principle

A scheduled task should NEVER do strategic redesign.

It receives a stable recipe and executes it.

If the recipe becomes inadequate:
1. stop the affected run safely
2. log the reason
3. revise the recipe outside the scheduled session
4. resume on the next run

This prevents long sessions from turning into uncontrolled improvisation.

# Account-risk rule

Amazon account actions must be human-like browser operations.

Do not:
- scrape Amazon in the background
- script Amazon search-result fetching
- reuse another creator's affiliate links
- infer approval status
- create unsupported claims about product availability

Read pages as they load in the normal signed-in browser.
