## Comparison method

Every unmatched span was emitted with surrounding context and read across 41 bounded chunks (000–040), without truncated output. Baseline text and all variant differences were retained; a matching token run is not a claim that the entire file is byte-identical. Exact duplicates are identified only by hashes. Whitespace-normalized comparison is a reading aid only: captured originals were never normalized or replaced by diffs.
