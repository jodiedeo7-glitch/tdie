# TDIE PREMIUM DFY CONTENT CALENDAR — PRODUCTION RULES

Status: AUTHORITATIVE — 29 September 2026
Scope: Premium Monthly DFY Content Calendar only.
Precedence: This file governs calendar production wherever it conflicts with the general image-generation master. The general image master remains authoritative for photographic quality, identity locking, persona/world rules, and general image-prompt hygiene.

## 1. The calendar is NOT Jodie's personal image-generation workflow

Do not import Jodie's personal generation sequence into the Premium DFY Content Calendar.

Calendar production does NOT say:
- Gemini first for every person image
- Nano Banana Pro second
- Canva never
- any fixed image-generator sequence

Those are Jodie's personal workflow rules. They are not customer-facing calendar rules.

For every calendar image:
- write a complete, standalone, model-agnostic image prompt;
- recommend Nano Banana Pro only as an optional choice when high-quality reference-heavy/person work makes it useful;
- the member may use any image generator she prefers;
- do not require the member to own Gemini, Nano Banana, Higgsfield, Canva, Midjourney, Grok, Kling, or any other named generator;
- the calendar sells the creative direction and finished prompts, not a locked vendor stack.

## 2. Video production is model-agnostic

Every Reel entry contains TWO separate production paths.

### VERSION A — ONE-STEP REEL
For a workflow that generates the visual motion AND renders the supplied on-screen text in the same generation.

The prompt must contain:
- scene/action;
- camera/framing/motion;
- duration and pacing;
- exact on-screen text;
- when each text line appears;
- placement/safe area;
- descriptive typography treatment;
- exact spelling and punctuation;
- no extra words, subtitles, logos, watermarks or invented text.

The prompt is a complete copy-paste video prompt. WAN may be the suggested workflow where appropriate, but the calendar must not depend on WAN ownership or availability.

### VERSION B — TWO-STEP REEL
For a workflow where the member generates the video first and adds on-screen text afterward in CapCut, Canva, Claude, or another editor.

The video prompt contains NO on-screen text instructions.

Then provide a separate:
- ON-SCREEN TEXT block;
- exact text, line by line;
- timing;
- placement;
- animation/treatment;
- safe-area instruction;
- editing note.

The two-step version is always usable even if the member uses a different video generator.

## 3. Static image prompts

Static image prompts must be standalone and model-agnostic. Specify composition, subject, action, setting, wardrobe/props where relevant, camera/framing, lighting, realism and mood. Use the research-derived creative rule for that day. Avoid generated lettering/text unless explicitly required by the asset.

Never force a particular image-generation service. Never say use Gemini first, then Nano Banana. Never assume the member has Jodie's reference sheet.

## 4. Research is upstream of every creative decision

Before writing the month:
1. Collect at least 40 genuine outlier posts from at least 25 same-niche, similar-creator, normally-not-viral accounts.
2. Record source/account, URL, date if visible, format, hook, opening frame, topic, mechanism, CTA and visible performance evidence.
3. Count recurring patterns.
4. Convert those patterns into explicit monthly build rules.
5. Build the calendar from those rules.
6. Only afterward run platform-rule, benchmark, tool-limit and niche-gap checks.

Do not substitute platform-wide averages for actual post-level research.

Research may override standing creative rules, except:
- no income/earnings claims on Meta surfaces;
- no invented products, prices or links;
- no faith content;
- no em dashes.

## 5. Required monthly Reel deliverable

Every Reel entry contains:
1. Hook/opening text
2. Creative concept
3. Static start-frame image prompt
4. VERSION A — ONE-STEP REEL prompt
5. VERSION B — TWO-STEP REEL video prompt
6. VERSION B — separate on-screen text instructions
7. Caption
8. CTA
9. Story adaptation when appropriate

Do not collapse the two Reel versions into one prompt.

## 6. The calendar is for the member

Write prompts so a beginner can copy, paste and execute them without knowing Jodie's personal workflow.

Never write:
- Run this through Gemini first.
- Then use Nano Banana.
- Generate in Higgsfield.
- Use my reference sheet.

Instead write what the finished asset needs to look and behave like.

## 7. Quality gate

Reject/rewrite any entry where:
- the image prompt dictates a vendor without a calendar-specific reason;
- the Reel has only one production path;
- the one-step and two-step versions are different concepts;
- the two-step video prompt contains text intended for the editor;
- exact overlay copy is missing from the one-step version;
- a static prompt contains unexplained generator-specific syntax;
- a prompt assumes access to Jodie's personal reference files;
- research evidence is missing for a claimed replication rule.

## 8. Relationship to the general image master

Use the general image master for photographic realism, identity/reference handling, Tommy Kate world, colour handling, prop variation, standalone-prompt discipline and general image quality.

Do NOT inherit its personal tool_order into the Premium DFY Content Calendar.
