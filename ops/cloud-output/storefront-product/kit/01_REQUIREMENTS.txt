REQUIREMENTS
Read this before anything else.

THE PRODUCT HAS TWO NORMAL MODES

TIME-SAVING PATH
Use paid Claude + connected image tools + Pinterest API after Standard approval. The machine handles the repetitive downstream work. Amazon product research and Amazon-side list creation remain customer-owned actions unless the customer is independently eligible for an approved Amazon API integration.

CREDIT-SAVING PATH
Use a lower-cost Claude or ChatGPT plan and do the same downstream operations manually. No scheduled-task subscription is required. Use the native Pinterest composer/scheduler and a manual image workflow.

You can mix the modes. For example: automate image creation but publish Pins manually.

IMPORTANT: The product never treats your personal founder subscriptions, unlimited access, credits, discounts or model access as customer entitlements.

WHAT YOU NEED FOR THE TIME-SAVING PATH

1. A paid Claude plan with Scheduled Tasks. Current Claude documentation says Scheduled Tasks are available on paid plans and run in the cloud. Scheduled tasks can use connected tools, skills and plugins. Scheduled tasks do not require your computer to stay awake. citeturn545658search0turn545658search3

2. A Claude project/account workspace for the Storefront working files in the automated path.
   Current Claude documentation says Scheduled Tasks use files saved to your Claude account and cannot be tied to a folder on your computer. The local-folder/browser route therefore belongs to manual or desktop-local work, not the default cloud scheduler architecture. citeturn545658search0

3. An image provider with commercial-use rights for your use case.
   Current benchmark:
   - OpenArt Plus: current pricing shows $34 list / $27 displayed promotion, 12,000 credits per month, OpenArt MCP and commercial-use rights. OpenArt MCP uses the same account credits and library. citeturn545658search11turn545658search1
   - Higgsfield: model-specific website Unlimited plans exist, but Higgsfield says MCP/CLI and other non-website surfaces use standard credits. Never assume website Unlimited applies to MCP.
   - Gemini API: pay-per-image, useful for a low-cost API route.
   - OpenAI image API: usage-priced, useful for selected editing/generation jobs.

4. Pinterest:
   - Native/manual path: Pinterest business account.
   - API path: your own Pinterest developer app, Trial access first, then Standard approval. See 13_PINTEREST_API_APPLICATION.txt.
   - Do not confuse API approval with Pinterest account approval. They are different.

5. Amazon:
   - Influencer path: approved Amazon Influencer account and Storefront.
   - Associates-only path: approved Amazon Associates account and a compliant publishing destination.
   - Amazon product selection, ASIN selection, Special Link creation and Idea List creation happen in the customer workflow unless an eligible approved Amazon API is being used.

6. A rights-cleared reference image only when you use one.
   A marketplace image is not rights-cleared just because it is publicly viewable.
   Amazon clothing photos are NOT an exception.
   You can absolutely create clothing flat lays. What you cannot assume is permission to feed Amazon-hosted clothing photos into an AI generator. Use written product attributes or customer-owned/licensed references.

7. Backup state.
   Keep a local backup of the Storefront working files even when the production files live in the Claude account/project.

WHAT YOU NEED FOR THE CREDIT-SAVING PATH

You can use:
- Claude Free or a lower-cost paid Claude plan for planning/copy.
- ChatGPT Free, Go or Plus for manual planning/image work when image generation is available to your account.
- A browser-based image provider you can afford and use commercially.
- Pinterest native creation and scheduling.
- Amazon product research and link/list creation manually.

Exact free limits and app features change. Verify your account before building around a feature.

AMAZON CLOTHING RULE
Amazon's current Associates Program Policies do not create a clothing-specific exception to the Program Content rules. Program Content cannot be altered except for limited resizing/truncation, cannot be redistributed, and cannot be used as a general-purpose AI training or transformation source. This is a rights/use rule, not a category rule. citeturn959482search6

PINTEREST API RULE
For API scheduling/publishing, the user must choose each Pin to be published. The product therefore uses a positive APPROVE action in API mode. The old negative-only PULL queue is not the API publication approval mechanism. citeturn959482search3

PINTEREST AUTOMATION RULE
Pinterest's Terms prohibit unauthorized automated access and automated scraping. The normal customer paths use either the approved Pinterest API or native manual Pinterest controls. citeturn959482search0

★ CREDIT-SAVING PATH
Any time this guide says "connector" or "scheduled task", the manual equivalent is the same operation done by you in the normal web/app interface.

★ TIME-SAVING PATH
Any time this guide says "manual", you can replace that operation with an approved connector/API after verifying the capability on your account.

WHAT IS NOT REQUIRED
- No Amazon browser automation.
- No Canva for the core workflow.
- No video-generation tool.
- No separate missed-run task.
- No website on the Influencer path.
- No Pinterest API approval to use the manual path.

PRODUCT INTAKE
Each ready look needs:
- look name and date
- ASIN for each item
- your own plain-language product description, color, material and important visual details
- your own compliant Amazon Special Link, or an eligible approved API-generated link
- destination URL
- optional customer-owned/licensed reference image
- rights confirmation for every external reference image used

The scheduled workflow never invents missing product data.

FINAL RULE
When the provider, connector, Amazon path or Pinterest capability changes, update the matrix in 14_AI_PROVIDER_MATRIX.md and MY_RECIPE.txt before changing production instructions.
