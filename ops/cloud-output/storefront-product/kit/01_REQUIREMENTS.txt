REQUIREMENTS

Read this before anything else.

CORE REQUIREMENTS

1. CHATGPT WORK
The automated storefront path requires a ChatGPT plan/account with access to Work and Scheduled Tasks. Current OpenAI documentation says Work is not available on Free or Go; availability on other plans can vary by account, region and workspace permissions. Check current Work access before purchase/setup.

IMPORTANT PLAN GATE
- Work automation path = requires Work access.
- Free/Go customers must not be told that ordinary Scheduled Tasks alone provide the full storefront automation.
- The lower-cost/manual path can still use ChatGPT for preparation and native Pinterest for final scheduling, but it is not the same unattended Work workflow.

Work Cloud is preferred for the true while-you-sleep path. Work Local is the fallback when the workflow requires a local folder or local browser session.

2. AMAZON
You need an approved Amazon Associates account.

If you want the Amazon Influencer Idea List path, you also need Amazon Influencer approval and a storefront.

Amazon's PA-API 5 is deprecated. Amazon's current successor is Creators API. Do not assume you have Creators API access. The customer workflow may use customer-supplied Amazon product data and authorized affiliate links instead.

3. PINTEREST
You need a Pinterest business account with public boards.

Pinterest's native scheduler supports standard Pins up to 30 days ahead and up to 10 future Pins at a time.

4. IMAGE PROVIDER
Higgsfield is the preferred connected image provider when the customer selects that path. Higgsfield officially supports ChatGPT integration. A paid Higgsfield subscription is required for its ChatGPT connection.

If the customer uses another supported image provider, record the exact provider, model, plan and commercial-use rights in MY_RECIPE.txt.

5. METRICOOL
Only required for TIME-SAVING publishing.

Metricool's MCP can connect to ChatGPT and can create, schedule, publish and update posts on connected networks within the customer's Metricool plan limits.

Metricool Free has a 20-published-post monthly limit. The storefront does not assume a particular Metricool tier. Customers who exceed the Free limit need a paid plan.

6. GOOGLE DRIVE
Required for the preferred CLOUD state/asset path when the workflow uses Google Drive.

ChatGPT can connect to Google Drive and, where the required permissions/actions are enabled, read and update supported Drive-family files.

7. THE BRAND CLOSET™
Only required for the optional Outfit of the Day automation.

WHAT THE CUSTOMER DOES NOT NEED

No separate desktop-browser automation subscription is required by this storefront kit.
No Pinterest API developer application is required for the normal customer path.
No Amazon PA-API 5 integration is required.
No website is required on the Amazon Influencer path.
No Instagram is required for the core storefront.

COST-SAVING PATH

Choose CREDIT-SAVING if you do not want a Metricool subscription.

ChatGPT builds the complete Pin package.
You perform the final Pinterest scheduling step.

TIME-SAVING PATH

Choose TIME-SAVING if you want to use the connected Metricool publishing path after you select each finished Pin and explicitly authorize that Pin's schedule. A scheduled task may prepare and route an approved Pin only when the required account actions are available.

IMPORTANT VERIFICATION GATE

Never promise publishing without customer approval. A successful setup test can confirm only the exact authorized action and the publisher evidence it returned; it does not prove unattended future runs or publication. Test one Pin only after the customer chooses the final image, confirms the destination resolves, verifies the exact public board and disclosure, reviews the title and alt text, and authorizes that specific scheduling action.

If board assignment, per-Pin approval, or publisher readback cannot be supported in the customer's account, mark the path blocked or manual. Do not claim the end-to-end workflow is verified.

COMPUTER REQUIREMENT

CLOUD mode: computer can be off during the run.
LOCAL mode: computer must be available for local work.

Never type passwords into a task prompt. Complete sign-in through the provider's own sign-in flow.
