REQUIREMENTS
Read this before anything else. This kit automates the downstream image, content and Pinterest work. It does not use an AI agent to browse Amazon or operate your Amazon account.

WHAT YOU NEED FOR THE CORE MACHINE

1. A paid Claude plan with Scheduled Tasks and the ability to use browser/local-file capabilities required by your chosen setup. Plans change, so check Claude's current plan and feature page before purchase.

2. Claude Desktop installed and connected when a scheduled task needs your local Storefront folder or browser. Claude's schedule itself can run remotely, but a task that needs your local folder or browser cannot complete that local portion while Desktop is offline.

3. A local Storefront folder that you will keep in the same location after setup. Do not rename or move it after creating the scheduled tasks. If you do move it, update the folder setting on every affected task.

4. Amazon Associates or Amazon Influencer access appropriate to your monetization path.
   The core machine does not log into Amazon, search Amazon, scrape Amazon pages, click SiteStripe, create Idea Lists, or collect Amazon Program Content for you.
   You choose products yourself and record the information the machine needs in PRODUCT_SOURCES.md.
   Advanced option: an eligible Amazon Creators API integration can reduce manual product lookup and link collection, but it is not required and eligibility is not universal.

5. A Pinterest business account and the public boards you want to publish to.
   Keep the boards public for production. The task checks the board before scheduling and stops if a production board is secret.

6. An image-generation provider with commercial-use rights for your use case.
   Recommended single-provider benchmark: OpenArt Plus. Current OpenArt Plus includes commercial-use rights and access to multiple current image models through OpenArt. Use the provider's current model list and credits at the time you set up.
   Other supported choices can be used when their current commercial rights and reference-image behavior meet the workflow:
   - Google Gemini API on a paid tier for a lower-cost, API-first path.
   - Higgsfield for customers who already use it. Higgsfield's MCP path uses standard credits even when the website plan has Unlimited access, so never assume website Unlimited means MCP Unlimited.
   The kit does not assume the founder's personal plans, discounts or unlimited access.

7. A reference image only when you own it or have explicit permission/license to use it in an AI workflow and in the final commercial content.
   Do not use Amazon product images, retailer images, marketplace screenshots, paid third-party course images, or any other third-party image as an AI input unless you have the rights to do so.

8. A backup copy of the Storefront folder before the first scheduled production run.
   The folder contains your recipe, queue, drafts and logs. Back it up again before changing the configuration.

OPTIONAL WEBSITE PATH

9. Associates-only buyers need a documented Amazon-approved publishing destination. In this kit that means your own website. If the site is a Weekend Ecosystem site on GitHub, the blog half can publish through the existing site workflow. Other site builders use the generated page file for manual publishing.

WHAT IS NOT REQUIRED

- No Instagram for the core machine.
- No coding for the core workflow.
- No face on camera.
- No Amazon browser automation.
- No Canva for the core image workflow.

PRODUCT INTAKE

Before a look can run, PRODUCT_SOURCES.md needs:
- look name and date
- ASIN for each item
- plain-language product description, color, material and important visual details
- the Amazon Special Link you obtained yourself or through an eligible approved API path
- the destination URL for the look: your Idea List URL or your website page target
- optional reference image filename only when you own/license that image for AI use
- a rights confirmation for every uploaded reference image

TIME-SAVING PATH
Use a current connector/API or your chosen image provider integration where it is actually supported and authorized. The product does not require those connections.

CREDIT-SAVING PATH
Do the Amazon product selection and Idea List creation manually, then use the image provider manually for only the images that need regeneration. The same downstream file formats and log state are used.

The HONEST PART

This product automates repetitive downstream work. It does not promise sales, approval by Amazon or Pinterest, or access to a specific platform/model forever. Follow the current terms of the services you connect.

The Pinterest queue remains reviewable: every Pin is logged before scheduling, and you can mark it PULL before its posting deadline.
