STOREFRONT PATHS

Your Pins need a destination. Choose the path that matches your Amazon account.

====================================================================
THE AMAZON INFLUENCER PATH: IDEA LISTS
====================================================================

You need:
- approved Amazon Influencer access
- an Amazon storefront

Each look gets its own Idea List containing the products in that look.

TIME-SAVING: after the customer supplies and authorizes the exact products and links, use an actually tested supported integration to create or verify the Idea List. Do not assume Amazon Idea List creation is available through ChatGPT.

CREDIT-SAVING / MANUAL: the customer creates the Idea List in their own Amazon Influencer storefront, adds the approved products, then supplies its live URL. ChatGPT or Claude can prepare the product checklist without requiring a paid automation step.

The Pin destination is the look's Idea List.

The automation must verify that the list resolves before the Pin enters the publishing queue.

If an Idea List is pending review or unavailable:
- do not substitute another look
- keep the Pin queued
- record the exact state

No website is required for this path.

====================================================================
THE ASSOCIATES-ONLY PATH: YOUR OWN SITE
====================================================================

You need:
- approved Amazon Associates
- a website where a shop-the-look page can live

Each look gets a page containing:
- look title
- original Pin images
- product descriptions
- your authorized affiliate links
- required disclosure

The page URL is the destination for both Pins.

TIME-SAVING: use an authorized, tested website integration to write the approved page and verify its live URL.

CREDIT-SAVING / MANUAL: ChatGPT or Claude prepares the page copy, product-link list, disclosure and image filenames; the customer publishes the page in their site builder and returns its live URL for verification. No Work or connected website write is required.

The page must load before a Pin can be published.

====================================================================
SITE TYPES
====================================================================

1. A site the workflow can write to through an authorized supported connection:
The page can be generated and published as part of the workflow, subject to the exact site integration being available.

2. Any other site builder:
The workflow prepares the complete page package.
You publish the page yourself.
Pins remain queued until the page is live and verified.

Never claim that ChatGPT can publish to a site unless the customer's actual connected integration supports the required write action.

====================================================================
PUBLISHING PATHS
====================================================================

TIME-SAVING: METRICOOL

Metricool currently supports Pinterest scheduling and publishing and supports:
- Pinterest board selection
- Pin title
- Pin link
- alt text
- image/video media
- scheduled publication
- scheduled-post management
- CSV bulk scheduling

Metricool's MCP can connect to ChatGPT and can create, schedule, publish and update posts within the customer's Metricool plan limits.

For direct connected publishing, Metricool's current action accepts Pinterest media and can use connected Google Drive media through Metricool's supported external-media path. This avoids requiring public Drive permissions for the normal direct-publishing path.

The customer's Pinterest account must be connected to the correct Metricool brand.

IMPORTANT:
The exact combination of a recurring ChatGPT Scheduled Task automatically invoking the Metricool action must be tested in the customer's account.

The storefront test must also prove that the customer's production Pinterest boards resolve correctly through the connected Metricool account. A newly created board may require the Pinterest connection to be refreshed and synchronized before it is available to the publishing action.

If the task requires approval, the Pin remains awaiting_approval.
If the action fails, the Pin remains queued.
Do not describe the workflow as fully unattended until the end-to-end test passes.

BATCH FALLBACK:
If direct connected publishing is unavailable but the customer has Metricool, the system can prepare a Metricool CSV batch. Metricool currently recommends up to 50 posts per CSV and supports Pinterest board, Pin title, Pin link, alt text and media fields. CSV media URLs must be publicly accessible. This is a batch handoff, not unattended publishing.

CREDIT-SAVING: NATIVE PINTEREST

Pinterest's business scheduler currently supports standard Pins up to 30 days ahead and up to 10 future Pins.

ChatGPT prepares:
- image
- title
- description
- alt text
- board
- destination URL
- scheduled date/time

The customer performs the final scheduling action in Pinterest.

No Metricool subscription or Work access is required for this path. A lower-cost ChatGPT or Claude plan may prepare the copy and image prompt; the customer may run image generation directly in their chosen provider and upload the finished image to Pinterest. Preserve the exact-Pin review and scheduling-authorization gate even when scheduling manually.

====================================================================
AMAZON API
====================================================================

Amazon PA-API 5 is deprecated.

Amazon's current successor is Creators API.

Creators API can provide programmatic Amazon catalog access for eligible Associates/influencers, but the product does not require every customer to qualify for it.

Do not build customer instructions around PA-API 5.
Do not assume Creators API access.

====================================================================
AMAZON + PINTEREST STOREFRONT CONNECTION
====================================================================

An eligible Amazon Storefront can connect to Pinterest.

Treat this as a supplemental discovery/product-tagging path.

It does not replace the core Idea List or Associates-only destination architecture.

====================================================================
AFFILIATE DISCLOSURE
====================================================================

Every Pin must contain the disclosure required by the customer's current Amazon program terms and the exact disclosure configured in MY_RECIPE.txt.

Never invent disclosure wording.
Never omit the disclosure from a monetized Pin.

====================================================================
NO PRICES / NO AMAZON-HOSTED PRODUCT IMAGES
====================================================================

Do not put Amazon prices in:
- images
- titles
- descriptions
- alt text
- pages
- lists

Do not publish Amazon-hosted product images as the generated Pin asset.

Use original generated imagery or customer-owned/licensed imagery.
