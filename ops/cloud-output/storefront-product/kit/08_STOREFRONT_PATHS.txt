STOREFRONT PATHS

====================================================================
PATH A: AMAZON INFLUENCER + IDEA LISTS
====================================================================

Use this when the customer has Amazon Influencer approval and a Storefront.

Customer setup:
1. Create the Idea List in Amazon.
2. Add the products.
3. Record the public Idea List URL in PRODUCT_SOURCES.md.
4. The Storefront workflow never opens Amazon as an autonomous agent.

No website is required for this core destination path.

★ SAVE CREDITS INSTEAD OF TIME?
Create and maintain Idea Lists manually. This is already the required customer-owned step.

====================================================================
OPTIONAL INFLUENCER ENHANCEMENT: AMAZON STOREFRONT <-> PINTEREST
====================================================================

Pinterest currently offers an eligible-creator connection between Amazon and Pinterest. When an Amazon Storefront is linked, Pinterest provides an Amazon filter for product tagging, automatically applies affiliate links to tagged Amazon products, and automatically shows an affiliate-link disclosure on Pins with those affiliate links. citeturn959482search2

This is NOT the same thing as an Idea List.

Use it as a supplemental shoppable discovery path after checking eligibility.

Comparison:
- Idea List: your look destination, containing the products for that look.
- Amazon Storefront connection: Pinterest product-tagging workflow for eligible creators.
- They can serve different purposes. Do not remove the Idea List workflow simply because the connection exists.

★ SAVE CREDITS INSTEAD OF TIME?
Use Pinterest's native Amazon product-tagging workflow manually after connecting your Storefront.

====================================================================
PATH B: AMAZON ASSOCIATES ONLY + WEBSITE
====================================================================

Use this when the customer does not have Influencer approval but has an approved Associates account and a compliant website destination.

The site page contains:
- original AI styling images
- written product descriptions
- customer-provided compliant Amazon Special Links
- affiliate disclosure
- AI-image disclosure

Do not use Amazon-hosted Program Content as a reusable site image library.

A Pin should not point to a page that is not live.

====================================================================
PINTEREST METHOD
====================================================================

NATIVE UI
The customer creates and schedules each Pin in Pinterest's normal composer.

API STANDARD
The customer's approved Pinterest app uses OAuth and an explicit APPROVE gate. Each Pin must be chosen by the customer before publication. citeturn959482search3

LEGACY BROWSER AUTOMATION
Not a recommended course path. Pinterest Terms prohibit unauthorized automated access. See 13_PINTEREST_API_APPLICATION.txt.

====================================================================
AMAZON CLOTHING NOTE
====================================================================

Clothing can absolutely be the subject of an original AI flat lay.

The distinction is:
GOOD:
- written clothing attributes
- customer-owned clothing photos
- explicitly licensed manufacturer/seller imagery with transformation rights

NOT ASSUMED TO BE PERMITTED:
- Amazon-hosted product photos
- marketplace screenshots
- retailer screenshots

Amazon's current Program Content policy does not create a clothing-specific exception. citeturn959482search6
