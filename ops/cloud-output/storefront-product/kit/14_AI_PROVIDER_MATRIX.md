# Image and AI provider choice
This is a capability worksheet, not a price promise. Check the provider's current account screen and commercial terms before buying or generating.

| Work | Low-cost Claude/ChatGPT path | Manual alternative | Optional time-saving path |
|---|---|---|---|
| Planning and copy | Short requests on your existing plan, within account limits | Write from the supplied checklist | Tested scheduled runtime |
| Original styling image | One generation only if available and commercially permitted | Your own/licensed photo or original layout | Verified image connector |
| Persona | Optional, one rights-cleared reference | Person-free flat lay/collage | Tested provider/model supporting the reference |
| Correction | Revise only failed asset | Edit text/layout yourself | Same approved provider, within budget |
| Publishing | Prepare fields in chat | Native Pinterest scheduler | Tested approved publisher with explicit Pin approval |

Record provider, model, plan, interface (website/MCP/API), remaining allowance, per-image cost if any, commercial-use evidence and maximum spend in MY_RECIPE.txt.
Unlimited on a website is not proof of Unlimited on a connector/API. Founder subscriptions are not customer entitlements.
No image provider, developer approval, paid scheduler or AI plan upgrade is required for the manual path.
