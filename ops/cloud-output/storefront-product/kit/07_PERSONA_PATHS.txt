PERSONA INPUT
Use only the customer's own persona reference image or another image with explicit rights to use for AI transformation and commercial publication.

PRODUCT INPUT
Use written product attributes by default. Attach a product reference image only when PRODUCT_SOURCES.md confirms customer ownership/license.

REFERENCE ORDER
1. Persona reference image
2. Rights-confirmed customer-owned/licensed product reference image, if one exists

Never attach an Amazon marketplace screenshot as a substitute.

MODEL GUIDANCE
- Nano Banana 2: general-purpose reference/image workflow and strong all-around choice when available.
- Nano Banana Pro: use when the job benefits from more complex instructions, higher control or difficult edits.
- Seedream 4.5/5-series: useful for person-free styling, flat lays and fashion/product compositions when the current provider exposes the model.
- GPT Image: useful for targeted edits and cases where the OpenAI workflow is preferred.

These are workflow recommendations, not vendor guarantees. Use the current 14_AI_PROVIDER_MATRIX.md.

QUALITY GATE
Check identity, required products, body/hand artifacts, realism, framing, no logos/text, no unintended IP, and commercial-use rights.

★ SAVE CREDITS INSTEAD OF TIME?

CONSISTENCY
The exact persona reference stays fixed. Do not invent identity traits that are not visible in the reference.
