Read my site's existing layout, styles and components first and match them exactly: same fonts, colors, spacing, header and footer. THE DATA
- A folder src/lifestyle/ holds one JSON file per look plus that look's images, side by side.
- File names: <slug>.json, <slug>-pin1.jpg and <slug>-pin2.jpg. Images are portrait, roughly 2:3, at least 800 pixels wide. Also accept .jpeg, .png and .webp, and match each JSON image to its file by name without the extension, so "<slug>-pin1.jpg" in the JSON still finds <slug>-pin1.png.
- JSON fields: slug, title, date (YYYY-MM-DD), category, season (a season or holiday name, or "Evergreen"), intro, images (array of { file, alt }), ideaList (the look's Amazon Idea List, or empty on the Associates-only path), items (array of { name, link, note (optional) }).
- Categories: write a list of 6 to 10 categories that fit my theme (ask me my theme in one question if you can't tell from the site). Each has a slug (lowercase, hyphens only), a name and a one-line blurb in my voice.
- Be forgiving: an image whose file isn't there is dropped; a look left with no images or no items is skipped; a look whose category isn't in the list is skipped; a JSON file that doesn't parse is skipped with a warning. Only a look slug equal to a category slug, or two looks with the same slug, stops the build, with a clear error naming the slug. Read only the .json files, never the README.
- Add a README.md inside src/lifestyle/ explaining the format in plain words, with one example JSON.

THE PAGES
- /lifestyle: the hub. A headline, one line about the section, a grid of category cards (with a look count or "Coming soon"), then the latest 24 looks as image cards.
- /lifestyle/<category>: a heading, the blurb, and every look in that category as image cards.
- /lifestyle/<slug>: one look. Top to bottom: an eyebrow linking back to its category, the title as the H1, the intro, a one-line affiliate notice, the images, then "Shop the look": a numbered list of every item, each name linked to its item link. If the look has an ideaList, a button under the list: "Shop every piece on Amazon". Then up to 4 more looks from the same category.
- Every Amazon link opens in a new tab with rel="sponsored nofollow noopener".
- Every page in the section ends with this disclosure: "As an Amazon Associate I earn from qualifying purchases. Every link on this page is an affiliate link: if you buy through it, I earn a small commission at no extra cost to you." And this line: "The images on this page are AI-generated styling photos. The linked pieces may look slightly different in real life."
- No prices anywhere. Ever. Amazon prices change by the hour.
- Add Lifestyle to the site navigation and footer.

WRITTEN FOR GOOGLE
- Each look page's HTML title is the look's title (the search phrase people type), and its meta description is the intro, cut to 155 characters at a word boundary.
- One H1 per page. Images carry their alt text from the JSON and use the site's image optimization; the first image loads straight away, the rest lazy-load.
- Each look page sets its social share image to its first image, and has a canonical link tag with its full address.
- Add the hub, every category with at least one look, and every look page to the sitemap. A category with no looks yet is left out of the sitemap and marked noindex.
- Clean, flat URLs with no dates, using the same trailing-slash form as the rest of my site, everywhere (links, canonical tags, sitemap).
