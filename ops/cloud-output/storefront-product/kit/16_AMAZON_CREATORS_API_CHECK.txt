Checked 6 October 2026. Read with 08_STOREFRONT_PATHS.txt and 14_AUTOMATIC_EXECUTION_CONTRACT.txt. Supersedes older API summaries; does not certify account access.

WHAT AMAZON DOCUMENTS
Creators API gives software catalog access through SearchItems, GetItems, GetVariations and GetBrowseNodes. Its introduction requires marketplace Associates enrollment, registration, credentials and at least 10 qualifying sales in the past 30 days for PA API access through Creators API.
https://affiliate-program.amazon.com/creatorsapi/docs/en-us/introduction

POLICY CHECK
Use must primarily promote Amazon. Each use of catalog content must link to its relevant Amazon page; generic storefront links are not automatically sufficient.
Image files cannot be cached; image links can be cached for 24 hours. Other catalog content has a 24-hour cache limit followed by refresh; ASINs have an exception. Client applications cannot cache catalog content. Omitting prices does not remove these rules. Less-than-hourly price/availability refresh requires timestamps and the prescribed disclaimer; displayed catalog text requires its own disclaimer.
Private keys must remain secret and cannot be disclosed to another person or entity.
Restrictions extend beyond training: model development/improvement and specified aggregation, analysis, extraction or repurposing are covered. "Not training" does not establish AI-selection permission.
Agents must identify themselves in requests, answer identity questions truthfully and obey access controls; human impersonation and CAPTCHA circumvention are prohibited.
https://affiliate-program.amazon.com/help/operating/policies

OUR SETUP RULES (operational requirements, not Amazon approval)
Do not describe Claude or ChatGPT product selection as confirmed or likely allowed solely because SearchItems exists. Obtain written clarification for the exact proposed processing/provider arrangement where permission is uncertain; keep the answer with the connection record.
Never paste private credentials into chat, a client packet or a shared recipe. Verify credential protection in the customer's own permitted connection. No shared founder key for customers.
Until required checks pass, mark AI-assisted API sourcing UNVERIFIED. Keep separate evidence for permitted use, credential security, successful current catalog requests, cache refresh, correct destinations and agent identification. Catalog access does not prove Idea List creation, publishing or scheduled execution.
Do not download API product photos as generation references. Use customer-owned or appropriately licensed references. Original generated imagery does not establish permission for upstream catalog processing.

TIME-SAVING PATH
Use the customer's permitted, tested connection after checks pass. Record exact tool, account, timestamp and results. Preserve queued work when access fails.

CREDIT-SAVING / MANUAL PATH
The customer selects products and obtains authorized links using Amazon's own account tools, then supplies a product checklist. Either Claude or ChatGPT can organize the outfit and draft original copy. Verify linked items before scheduling. API eligibility and a paid sourcing agent are not required.
