Start here

THREE WAYS TO RUN IT
====================================================================

TIME-SAVING (the true while-you-sleep version)
The agent runs the complete approved workflow. ChatGPT Work handles its connected steps; a permitted, tested browser operator handles browser-only account actions. Cloud can run with your computer off only when every required step works in that runtime. Local browser steps require your computer on. Setup records and tests the exact route before enabling tasks.

CREDIT-SAVING
Use the ChatGPT or Claude plan you already have to write the copy and the image prompts. You run the image tool yourself and schedule the finished Pin in Pinterest's own scheduler. No Work plan or Metricool needed.

MANUAL
Use the recipes as checklists and do each step yourself. Slowest, cheapest.

You can mix them (for example: AI writes everything, you make the images) and switch any time. The rules on disclosure, links, public boards and duplicates are the same on every path.

CHATGPT, CLAUDE OR BOTH
You do not need subscriptions to both. Either assistant can guide the setup interview, prepare your curation profile/calendar, organize supplied product facts, write image prompts and Pin copy, review returned images, prepare the optional blog/Instagram files, and maintain the records available to it. External sourcing, link capture, image generation, account writes, publishing and recurring execution require the actual tools/access tested for that route; ordinary chat alone is not proof of those capabilities. The kit's current automated instructions target ChatGPT Work. A Claude-only unattended route must pass its own complete capability tests before it is represented as supported. With manual external steps, either assistant can guide the complete workflow.
For a mixed setup, name one lead assistant and one operator per external write. Both use the same current recipe, product packet, approved assets and state. Handoffs include LOOK_ID/PIN_ID, completed actions, returned service IDs, pending work and blockers. Never assume the other assistant can see this chat or its latest edits. Test the handoff before recurring execution, and keep a manual alternative for any unavailable action.

====================================================================
AUTOMATIC OR REVIEW FIRST
====================================================================

On the time-saving path, setup asks one more question.

AUTOMATIC: you approve the rules once (which accounts, boards, links, image tool, budget, pace and channels). After that, every Pin that passes every check is scheduled without asking you again. This is the hands-off version.

REVIEW FIRST: every finished Pin waits for you to say yes before it's scheduled.

Either way, every Pin is checked first: the image, the link, the public board, the #ad disclosure, the title and the alt text. Nothing with a missing check goes out.

====================================================================
YOUR PART AFTER SETUP
====================================================================

AUTOMATIC: no weekly product-picking, link-copying or Idea List homework. The agent sources products and builds destinations through the account routes tested during setup. You receive a short run report and can request changes or pulls. Re-sign-in, security checks or a revoked connection can interrupt an individual step; the queued work is retained.

CREDIT-SAVING / MANUAL: if you choose this route, you supply product rows and links, create the list or page, run image generation and schedule the finished Pins. MIXED: your saved recipe names exactly which steps you chose to do yourself.

Type PULL in the state sheet's PULL column (cloud) or next to the Pin in pin-tab.md (local/manual). The next reconciliation imports the request into state, cancels through the tested route and verifies removal. An unavailable cancellation route is reported, never described as a successful pull.

====================================================================

WHAT IT DOESN'T PROMISE
====================================================================

Sales. Pinterest is search, and Pins get found over weeks and months, not hours. This kit builds and runs the machine. What people buy is up to them and Amazon. It also can't promise that every outside service (ChatGPT, Metricool, Pinterest, your image tool) will behave the same in your account as in mine, which is why setup tests each connection before relying on it.
