THE WHILE-YOU-SLEEP STOREFRONT™
Start here

Your Amazon product choices become Pinterest pins that go out on a schedule, pointing people who are already searching for the look straight to your Idea Lists (or your own shop-the-look pages).

You set it up once. After that, scheduled work can build the downstream work: it takes the products and affiliate links you provide, makes the images, writes the Pin copy, prepares the queue and, in the approved API path, can publish only Pins you explicitly approve. Product selection and Amazon-side actions are deliberately kept outside the automated agent path. On the Influencer path, you still create the Idea List yourself, then the machine takes over. On an Associates-only site path, you may also paste a generated page yourself. 08_STOREFRONT_PATHS.txt explains the two paths.

Two things you should know before you start, because I'd rather you hear them now than find out on day three:

1. Scheduled Tasks run in Claude's cloud and can use connected tools. Current Claude documentation says scheduled tasks use files saved to the Claude account and cannot simply be tied to a computer folder. The Time-Saving architecture therefore uses cloud/account state. Local folders are for backup and manual work.
2. Every Pin is written to the queue before publication. In API mode, you must explicitly APPROVE each Pin. In native Pinterest mode, you create/schedule it yourself. PULL remains a removal/hold control, not API publication approval.

  2. Open the Setup Guide PDF and follow the numbered steps. It tells you exactly when to paste each file.
  3. That's it. The PDF is written for someone who has never scheduled a task in her life.

HOW LONG IT TAKES

Setup is designed to be short once your accounts are ready. The recurring build is downstream of your product intake: you choose the products and create the destination list or page, then the task handles image creation, copy, scheduling and logging. That boundary is intentional.

★ Prefer to save credits instead of saving time? Use 12_OPERATION_MODES.txt and the starred manual callouts in the recipes.\n\nWhat it does NOT promise: sales. Pinterest is search. Pins get found over weeks and months, not hours, and nobody can tell you when a pin will get its first click. This kit builds and runs the machine. What people buy is up to them and Amazon.
