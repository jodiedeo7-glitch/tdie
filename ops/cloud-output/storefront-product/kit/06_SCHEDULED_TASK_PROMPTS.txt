THE SCHEDULED TASK PROMPTS
Three jobs: the weekly themed-look build, the nightly Outfit of the Day run (Brand Closet™ members only), and the maintenance/recovery task. The maintenance task absorbs pull, verification, recovery and incomplete-work reconciliation. Each prompt is complete on its own. Your setup chat already copied them into MY_SCHEDULED_TASKS.txt with your folder, time zone and times filled in: paste from that file, not this one. This file is the master copy.

In the prompts below, «FOLDER» is your While-You-Sleep Storefront folder, «TZ» is your time zone (a named zone such as America/Chicago) and «TIME» is the run time from MY_RECIPE.txt. The setup chat fills them in.

If the app's schedule field won't take a choice below (two days a week, Sunday to Friday, two times a day), use the fallback written under it.

Every task needs its folder: set each task's folder field to your While-You-Sleep folder. The first time each task runs, the app asks you to allow that folder, and an unanswered ask stops the run. Once all configured tasks exist, run each one once by hand while you're at the computer (Run now) and allow the folder when asked.

You are the maintenance and recovery task for The While-You-Sleep Storefront™. Time zone: «TZ». Every time and date you use is in «TZ».

JOB

3. Process retryable failures within the retry bounds in 12_MAINTENANCE_RECIPE.txt. Never create a second external object when an external ID already exists.

Structured state is authoritative. Do not infer state from chat history, filenames or browser history. Every look, lesson and Pin has a deterministic ID. Preserve publisher, external ID, destination URL, media reference, copy and scheduled time. No duplicate creation. No passwords. No em dashes.

Use the browser only when the selected publishing adapter cannot perform the required operation or verification. If the browser freezes, open a fresh tab and retry once within the recipe's bounds. If the operation cannot be safely verified, leave the item in its current retryable/action-required state rather than guessing.
