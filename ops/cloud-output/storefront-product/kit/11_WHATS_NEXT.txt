Use paid Claude scheduled work, a connected image provider and the approved Pinterest API path after Standard approval.

2. CREDIT-SAVING PATH
Use a lower-cost Claude or ChatGPT plan, create the images manually, write the copy manually or with your AI chat, and publish/schedule Pins through Pinterest's native tools.

3. PINTEREST API
Read 13_PINTEREST_API_APPLICATION.txt.
