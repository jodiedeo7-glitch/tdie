OPERATION MODES
Every automated or credit-heavy step has both a low-cost Claude/ChatGPT route and a manual alternative.

STEP                    TIME-SAVING                              LOW-COST CHAT ROUTE                           MANUAL ALTERNATIVE
Plan looks              Supported scheduled runtime prepares    One short batch request from written notes     Choose one look from your own calendar
Select products         Read customer-approved intake           Ask chat to organize facts you supply          Select ASINs and create links/lists in Amazon
Create images           Verified provider connector             Generate one selected image within limits      Use your own/licensed photo or original layout
Write copy              Generate from verified product intake   One title/caption/alt-text request              Write from the template and review yourself
Build destination       Authorized supported site connector     Ask for one page from supplied product rows    Create Idea List or paste page in site editor
Queue/approve           Persist full record, HOLD until approval Review one finished Pin in chat                Review image/copy/link/board/date in composer
Schedule                Tested approved connector/publisher     Prepare fields; schedule yourself              Use native Pinterest scheduler
Reconcile               Read external records before retries    Paste current status into one review request   Check native Pinterest and Metricool separately
Pull/change             Act only on exact identified record     Ask for a change checklist                     Edit/remove the exact record in its own service

MANUAL MODE
No scheduled task subscription or developer application is required. Keep the same state fields so later automation can resume safely. AI is optional.
More minutes may save credits; a website plan is not automatically cheaper. Compare your actual volume and provider limits before upgrading.

MIXED MODE
Automate planning/copy, generate images manually, and keep publication manual. Add one connector only after the repeated step justifies its cost.

TIME-SAVING MODE
Record runtime, local/cloud mode, persistent state location, available connections, commercial image rights, timezone and publishing method. Run a draft-only test and read the result back before production.
For Pinterest developer API use, confirm current approval/access and required per-Pin user-choice rules. Metricool remains optional and needs its own account-specific test.
Use BUILD/QUEUE ONLY when a required capability is unverified.

COST CONTROL
Use one image first; reuse a valid asset and fix only the failed one. Set a maximum budget before generation. Never silently upgrade plans or switch models.
Website Unlimited, connector/MCP credits and API usage may be different allowances. Verify each surface on your own account.
Check current plan availability; this kit does not guarantee a feature on a named paid or free plan.

LOCAL VS CLOUD
Local runs require the configured host and state path. Cloud runs require connected accessible state and tools. Test the actual run environment, including its ability to read and write state.
Do not promise a catch-up run, PULL sweep or schedule persistence until observed. Approval of one Pin never approves future Pins.
