# While-You-Sleep Storefront customer candidate 4

This candidate contains every numbered customer source file 00-13 and the 14-page guide. The visual standard requires two distinct Pin stories: a deliberate product edit and a relevant lifestyle moment using the authorized persona and world, or a distinct in-situ scene. A different headline on the same composition fails. Typography, full-item framing and phone readability are checked after generation. Blog pages use clean photography, an editorial lifestyle hero, factual item cards, individual shopping buttons, disclosures and responsive screenshot QA. Low-cost and manual alternatives remain available.

The PDF includes actual product-edit and Tommy Kate lifestyle examples. The ZIP includes all numbered sources, the guide and its member-hash manifest. RELEASE_CANDIDATE_MANIFEST.json records current SHA256 values and release_ready=false.

Two actual Pinterest publications, dependent Instagram publication, buyer delivery and remaining release checks must be verified before release.
