2. Check every board in MY_RECIPE.txt is public (R11). If one is secret, stop and tell me which.
3. Schedule every leftover pin logged "built" first (recipe Part 7).
4. Build the next 7 days of looks at my pace, starting from the first day with no pin 1 scheduled, from the THEME CALENDAR and EVERGREEN BANK, following 03_THEMED_LOOK_RECIPE.txt Parts 2 to 7 exactly, for my path (persona or no persona; Influencer or Associates-only).

Only if all of that fails, end the run cleanly (keep what's built, log it, release the browser lock) and tell me what failed and the exact steps to fix it, for example: open Chrome, sign in to Pinterest, then run this task again. The Pinterest blank-page rule (two blanks in a row, stop) always wins over this block.
