A link to a signup form converts poorly. A link to something specific someone wants converts well.

That's the whole difference between "join my newsletter" and "get the 30-day launch checklist." Same email address, same list, wildly different conversion — because one asks for a favor and the other makes a trade.

Each pillar gets one. It should solve one specific problem for the exact reader of that pillar. Not a general lead magnet for your whole brand — a targeted one for that topic.

What makes a good one

Specific over comprehensive. A checklist beats an ebook. People download ebooks and never open them; they use checklists the same day.

Fast. Something usable in under an hour.

Made of what you already have. Your inventory has these in it — a framework from a lesson, a process from a call, the list you sent one person in a DM.

Genuinely free. No membership required, no trial, no partial version of a paid product. This is the rule from Module 11 and it's worth repeating because it's the one most often broken by accident.

01

Build the resource

Copy this prompt
Build a lead magnet for the [PILLAR] pillar. Source material above.

Format: [checklist / template / worksheet / swipe file]
Audience: someone who just read my article on [topic] and wants
to act on it today
Length: 2-4 pages. Usable in under an hour.

Use my Canon File for voice and brand.

Rules:
- One specific problem, solved completely
- Actionable steps, not explanation
- No product pitching inside it. One line at the end pointing to
  [product] is enough.
- Return it as clean markdown I can convert to PDF.
02

Turn it into a PDF

Simplest reliable route: paste the markdown into Canva or Google Docs, apply your brand colors and fonts, export as PDF.

If you want it fully automated, ask Claude to generate it as styled HTML and convert that to PDF — but do that once you're producing these regularly. Tonight, use the tool you already know.

03

Build the landing page

Copy this prompt
Build src/pages/resources/[slug].astro using PageLayout.

Contents:
- Headline naming the specific outcome
- 3-4 bullets on what's inside
- An image or mockup of the resource
- A signup that links to [YOUR HOSTED FORM URL] for this resource
- Nothing else. No nav distractions, no other offers.

Use my Canon File for brand. Complete file, ready to paste.
04

Set up delivery

In your email platform: create a form specifically for this resource, set an automation that sends the file immediately on signup, and tag the subscriber with the pillar topic.

The tag matters more than it looks. Six months from now you'll know which topic each subscriber came in through — which tells you what to build next and who to send it to.

Then get the hosted URL for that specific form and put it in the pillar's freeResource prop.

If you get stuck
Where do I host the actual PDF file?

Your email platform delivers it as an attachment or hosted link in the automation. Don't put the file on your website — a URL that reachable gets shared and bypasses the signup entirely.

Someone found my gated PDF without signing up

Then it's reachable at a public URL. Anything in your site's public folder is public — no login, no gate, no exception. Move the file to your email platform's delivery and remove it from the site.

I don't have time to build one per pillar

Build one for your strongest pillar tonight. Leave the rest empty using the omit rule from Module 11. One real resource beats five rushed ones and an empty slot beats a broken link.

Before you move on

One free resource, one landing page, delivery tested by signing up yourself.
