The idea

Run optimization as four separate passes, not one instruction. Asking for "SEO optimization" in a single request gets you a shallow version of all four — some keywords sprinkled in, a meta description, done.

Four audiences, four passes, one at a time:

Pass 1 — Google

Run a Google SEO pass on this article. Do not rewrite the whole
thing — return only what changes, with the exact replacement text.

Check:
1. Is the primary keyword in the title, first paragraph, and at
   least two subheads — naturally, not stuffed?
2. Do subheads match how people actually phrase the search?
3. Is there a meta description under 155 characters that earns
   the click rather than describing the page?
4. Are there internal links to my related articles, in context?
5. Is any section thin enough to be a ranking liability?

Pass 2 — Pinterest

Run a Pinterest SEO pass. Pinterest is a search engine, not a
social feed — treat it that way.

Give me:
1. Five pin titles, each targeting a different search phrase
   someone would actually type
2. Five pin descriptions, keyword-rich, 100-200 characters,
   no hashtag stuffing
3. The three board topics these belong on
4. Alt text for the featured image

Pass 3 — AI search

Run an AI-search pass. People are asking chatbots this question
now, and the article should be the source that gets cited.

Check:
1. Does each section open with a directly quotable answer?
2. Are claims specific enough to be worth citing — numbers,
   named steps, concrete examples rather than generalities?
3. Is there a clear definition of the core concept near the top?
4. Does the FAQ answer the questions people actually type in full
   sentences?

Return only what needs to change.

Pass 4 — the human

Read this as a skeptical reader who found it from a search result
and has no idea who I am.

1. Where would they stop reading? Be specific about the paragraph.
2. What claim would they not believe without proof?
3. Which parts sound AI-written?
4. What question does the article raise and fail to answer?

Do not be polite. Then fix each one.

Pass 4 is the one that most changes the article. Run it last and run it every time.

Roadblock — "The passes contradict each other"

Human wins. A keyword-perfect article nobody finishes doesn't rank, because the leaving is what gets measured.

Roadblock — "It rewrote the whole article"

Say: Return only the changes with exact replacement text and where it goes. Do not reproduce the full article. Full rewrites lose good material you didn't ask it to touch.

Deliverable

One pillar article through all four passes, updated and redeployed.
