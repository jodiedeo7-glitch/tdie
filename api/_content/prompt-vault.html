building an article from.

  your task, or you hit a hard stop you cannot bypass. Otherwise
  continue through until the task is complete.
- Give me the complete table at the end.

  with "PAUSED AT [row number]". I will say continue.

C1 · Pillar article

above is my actual method — it's the spine of the article. Use my
Canon File in project knowledge for products, prices, links, and voice.

LIVE FACTS — override anything that disagrees:

- Category: [category]

Rules:
- Never invent a product, price, or link. If a slot above says GAP
  or NONE, omit that slot rather than substituting something.
- Do not pad. If a section is thin, the fix is more specificity,
  not more sentences.
- No hype vocabulary. Follow the banned list in my Canon File.
- Return the complete article in markdown. Do not summarize what
  you wrote or suggest next steps.

D — THE FOUR SEO PASSES

Run in order, one at a time, on a finished article.

D1 · Google

Copy this prompt
Run a Google SEO pass on this article. Do not rewrite the whole
thing — return only what changes, with the exact replacement text.

Check:
1. Is the primary keyword in the title, first paragraph, and at
   least two subheads — naturally, not stuffed?
2. Do subheads match how people actually phrase the search?
3. Is there a meta description under 155 characters that earns
   the click rather than describing the page?
4. Are there internal links to my related articles, in context?
5. Is any section thin enough to be a ranking liability?

D2 · Pinterest

Copy this prompt
Run a Pinterest SEO pass. Pinterest is a search engine, not a
social feed — treat it that way.

Give me:
1. Five pin titles, each targeting a different search phrase
   someone would actually type
2. Five pin descriptions, keyword-rich, 100-200 characters,
   no hashtag stuffing
3. The three board topics these belong on
4. Alt text for the featured image

D3 · AI search

Copy this prompt
Run an AI-search pass. People are asking chatbots this question
now, and the article should be the source that gets cited.

Check:
1. Does each section open with a directly quotable answer?
2. Are claims specific enough to be worth citing — numbers,
   named steps, concrete examples rather than generalities?
3. Is there a clear definition of the core concept near the top?
4. Does the FAQ answer the questions people actually type in full
   sentences?

Return only what needs to change.

D4 · Human

Run last, every time. This is the pass that changes the most.

Copy this prompt
Read this as a skeptical reader who found it from a search result
and has no idea who I am.

1. Where would they stop reading? Be specific about the paragraph.
2. What claim would they not believe without proof?
3. Which parts sound AI-written?
4. What question does the article raise and fail to answer?

Do not be polite. Then fix each one.

F — IMAGES

F1 · The nine-part anatomy

Every image prompt should contain all nine. Missing parts are where randomness enters.

Copy this prompt
1. Subject — what's in frame
2. Setting — where
3. Lighting — "soft natural window light" / "golden hour"
4. Camera — "Canon R5, 85mm f/1.4, shallow depth of field"
5. Palette — exact hex codes, every time
6. Text — exact words in quotes, with placement
7. Composition — where the subject sits, where text goes
8. Realism — "a real photograph, not a 3D render, not CGI"
9. Format — "vertical 2:3" for pins

F2 · The locked shell

For any set of images that must look like one brand. Change only the swap fields.

Copy this prompt
LOCKED SHELL — change ONLY the swap fields. Every other word
stays identical across every cover.

A real photograph, not a 3D render, not CGI, of [SUBJECT],
[POSE], in [FIXED SETTING] with soft natural window light.
Canon R5, 85mm f/1.4, shallow depth of field.

Subject in the right third of frame. Text occupies the left
two-thirds, using that space generously — no empty dead area,
no floating text island.

Headline "[HEADLINE]" in [HEX], large enough to dominate the
left panel. Subtitle "[SUBTITLE]" beneath in [HEX].

A solid strip runs the full bottom edge, substantial in height,
fully opaque. Strip color: [BADGE HEX]. Label "[BADGE]" on it.

Where the text panel meets the photograph, a soft gradient
blend — no hard vertical seam.

Colors rendered rich and true-to-tone, not desaturated.

Palette: [your hex codes]. PHOTOREALISM — enforce hard.
Vertical format.

SWAP FIELDS: [SUBJECT] [POSE] [HEADLINE] [SUBTITLE] [BADGE]
[BADGE HEX]

THE ANTI-PROMPT

Included so you recognize it. Do not run anything shaped like this:

"Act as my Chief Systems Architect, CMO, SEO Strategist, Pinterest Strategist, AI Automation Engineer, Content Director, UX Designer, and Business Operations Consultant, and build my entire content system, website, product ladder, and 90-day launch plan…"

Three hundred lines, every role, every task at once. It fails three ways: the roles pull against each other and the output splits the difference; context collapses so late instructions outweigh early ones; and overlapping requests produce duplicate structures with no way to tell which is authoritative.

Role and context go in project instructions, once. Then one task per conversation, with a short specific prompt. Every prompt in this vault is built that way on purpose.
